Password Safety Tips
  • Use at least 12 characters
  • Include numbers, symbols, and both uppercase and lowercase letters
  • Avoid dictionary words or common phrases
  • Don't use the same password for multiple accounts
  • Consider using a password manager

Email Security Tips
  • Use a unique password for your email account
  • Enable two-factor authentication (2FA)
  • Be cautious of phishing emails
  • Regularly check for suspicious activity
  • Use an email alias for less important services
How It Works

Our password checker uses the "Have I Been Pwned" API to check if your password has been exposed in any known data breaches. For security, we use a technique called k-anonymity, which means your actual password is never sent over the internet. Instead, we send a partial hash of your password to check against the database of known breaches.
